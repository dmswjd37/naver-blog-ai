# STYLE EXAMPLE 3 - 해장을 위해 방문한 짬뽕순두부 식당

[학습 대상]
- 전날의 상황이 다음 날 방문 이유로 이어지는 도입
- 가게 이름과 실제 위치의 재미있는 차이를 짧게 언급하는 방식
- 재료와 국물 맛을 과장하지 않고 구체적으로 설명하는 방식
- 개인차가 있는 간과 맵기를 솔직하게 표현하는 방식

[복사 금지]
아래 글의 업체명, 지역, 메뉴, 원재료 정보, 가격과 경험은 새 글의 사실로 사용하지 않는다

[제목 스타일]
"""
시흥 오이도 해장하기 좋은 짬뽕순두부 맛집 강릉짬뽕순두부 주차 및 웨이팅
"""

[도입 예시]
"""
안녕하세요!

전날 오이도 와서 조개구이에 과음해버려서
다음날 아침에 해장시급 이슈로 짬뽕순두부
먹으러 달려갔어요~~

이름에는 강릉이 들어가지만
위치는 오이드라는 점 ㅎㅎ

오이도 짬뽕순두부 맛집으로 알려진
강릉짬뽕순두부 후기입니다:)

[스티커:오늘의맛집]
"""

[재료 안내 설명 예시]
"""
[소제목:매장에서 확인한 특징]
[구분선]

[사진:재료안내.jpg | 순두부와 콩국수 안내]

여기는 국내산 콩과 해양심층수로
매일 아침 순두부를 직접 만든대요!!

좋은 재료에 정성이 그만큼 많이 들어가는 거라
안내문을 보니 더 기대되더라구요 👏🏻
"""

[음식 설명 예시]
"""
[소제목:짬뽕순두부 한입]
[구분선]

[사진묶음:음식근접1.jpg, 음식근접2.jpg | 해산물과 순두부]

막 우와 엄청 푸짐하다 이런 느낌은 아니었지만
그냥 팍팍 퍼먹기엔 괜찮았고

막 냄새나거나 비리거나 하는 건 없었기 때문에
해산물 향 예민하신 분도 먹을 수 있을 것 같아요

특별한 맛은 아니었지만 오이도 온 김에
해장이 필요한 날 한 끼 해결하기에 좋은 듯!
"""

[문체 특징]
- 방문 이유가 분명해서 첫 문단부터 상황이 쉽게 이해됨
- "해장시급 이슈", "달려갔어요~~"처럼 일상적인 표현을 활용
- 안내문에서 확인한 사실과 직접 먹은 감상을 분리
- "엄청 푸짐하다"고 과장하지 않고 양과 맛을 솔직하게 표현
