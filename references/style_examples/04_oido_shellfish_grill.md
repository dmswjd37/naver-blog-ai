# STYLE EXAMPLE 4 - 재방문한 조개구이 식당

[학습 대상]
- 여러 번 방문한 식당을 소개하는 자신감 있는 도입
- 수상이나 인증 정보와 개인 만족도를 자연스럽게 연결하는 방식
- 술과 음식, 먹는 순서를 실제 식사 흐름처럼 설명하는 방식
- 가장 좋았던 조합과 재방문 의사를 강조하는 마무리

[복사 금지]
아래 글의 업체명, 지역, 메뉴, 수상 정보, 가격과 경험은 새 글의 사실로 사용하지 않는다

[제목 스타일]
"""
시흥 오이도 조개구이 블루리본 맛집 청춘조개 오이도본점 주말 예약후기 가리비타워 내돈내산
"""

[도입 예시]
"""
안녕하세요

조개구이 하나만 보고 오이도로 달려왔는데
여기 올 때마다 가는 맛집이 있어서 소개해
드리려고 후기 가져왔어요!!

수많은 오이도 조개구이 맛집 중에서도
블루리본 받은 찐 맛집이라 더 인기가 많고
구성, 퀄리티 모두 완벽 보장하는 곳이랍니다 👏🏻

청춘조개 오이도본점 후기입니다:)

[스티커:출발]
"""

[술과 식사 흐름 예시]
"""
[소제목:조개구이와 함께한 한잔]
[구분선]

[사진묶음:술사진1.jpg, 술사진2.jpg | 소주와 맥주]

그리고 술을 얼음 양동이에 넣어주셔서
계속 시원한 상태로 유지하면서 먹을 수 있어서
좋았어요!!

완전 센스 장난아니라 덕분에 시원한 소맥으로
갈증 제대로 해소할 수 있었습니다아ㅎㅎ

[스티커:짠]
"""

[음식 조합 설명 예시]
"""
[사진묶음:가리비1.jpg, 가리비2.jpg | 치즈 가리비]

위에서부터 차례대로 먹다 보니 어느새
도달한 1층 치즈 가리비 타임

이건 치즈가 한가득이라 가리비가 잘 안 보여서
잘 익었나 싶을 수 있는데 직원분께서 치즈가
충분히 잘 녹으면 먹어도 된다고 하셨어용

모짜렐라 말해뭐해요

정갈한 한식에서 퓨전 한식으로 넘어간 느낌이랄까
많이 짜지도 않고 치즈 풍미가 잘 느껴져서 강추!!

특히 바질페스토 올라간 게 향긋하니
조합이 너무 잘 어울려서 제 스타일이었어요 🙌🏻
"""

[마무리 예시]
"""
항상 만족하면서 먹고 와서 다음에도
재방문 할 예정이에요 💙

다른 맛집도 많이 있지만 기회 되시면
오이도 놀러 오셔서 맛있는 조개구이 먹을 겸
힐링하러 한번 들러보세요~~

청춘조개 오이도본점 후기였습니다:)

[스티커:끝]

[지도]
"""

[문체 특징]
- 재방문 경험은 사용자 입력에 있을 때만 활용
- 긴 설명 사이에 "모짜렐라 말해뭐해요" 같은 짧은 반응 문단을 삽입
- 먹는 순서, 직원 안내, 가장 좋았던 조합을 차례대로 연결
- "강추!!", "제 스타일이었어요"처럼 개인 취향임을 분명하게 표현
