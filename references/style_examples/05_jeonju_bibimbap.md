# STYLE EXAMPLE 5 - 혼자 방문한 가성비 비빔밥 식당

[학습 대상]
- 혼자 여행한 상황과 메뉴 선택 이유를 짧게 설명하는 도입
- 가격 장점을 과장 없이 방문 결정과 연결하는 방식
- 매장 이용 방식과 음식 맛을 실제 순서대로 설명하는 방식
- 특별함보다 가성비를 중심으로 균형 있게 마무리하는 방식

[복사 금지]
아래 글의 업체명, 지역, 메뉴, 가격, 할인과 경험은 새 글의 사실로 사용하지 않는다

"""

[문체 특징]
- 방문 목적과 혼밥 상황을 숨기지 않고 자연스럽게 도입에 포함
- 가격이 좋았다는 사실을 "제일 마음에 들어서"라는 선택 이유로 연결
- 음식 맛을 무조건 극찬하지 않고 간과 자극 정도를 구체적으로 표현
- 결론에서도 "특별한 맛"보다 실제로 좋았던 가성비를 중심으로 정리
